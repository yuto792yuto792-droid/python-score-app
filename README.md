# Python Score App

複数科目の点数を入力すると、平均点・最高点・最低点・合否を表示するPythonアプリです。

## Features

- 何科目でも点数を入力可能
- 0〜100点の入力範囲チェック
- 文字入力時のエラー処理
- 点数未入力時のエラー処理
- 平均点の表示
- 最高点・最低点の表示
- 平均60点以上で合格判定

## Usage

```bash
python score_app.py
## Tech Stack
